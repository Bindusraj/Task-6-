### 🎯 **Task 6: Conduct User Testing and Improve Design Based on Feedback**

This project focuses on **usability testing and design iteration** of the *To-Do List App UI* prototype created in Figma.
The goal was to test the interface with real users, gather insights, and refine the design for a smoother, more intuitive experience.

---

### 🧠 **Objective**

To understand how users interact with the design and make improvements based on their feedback — just like in real industry design validation processes.

---

### 🛠 **Tools Used**

* **Figma** – for designing & prototyping
* **Google Forms** – for collecting user feedback
* **Google Meet / Observation** – for live user testing

### 🧪 **How Testing Was Conducted**

* Shared the Figma prototype link with **5 users** (friends & classmates).
* Asked them to perform simple tasks like:

  * Add a new task
  * Mark a task as complete
  * Delete or edit a task
* Collected feedback using a **Google Form** (8 short questions).
* Observed usability pain points through screen sharing and direct comments.

---

### 🗒️ **Sample Feedback Form Questions**

1. Was navigation easy to understand?
2. Which screen felt confusing?
3. How would you rate the overall look & feel (1–5)?
4. Did you face any issue while completing tasks?
5. Suggestions for improvement?

---

### 📊 **User Feedback Summary**

| Issue Found                     | Suggested Fix                                    | Updated in Design |
| ------------------------------- | ------------------------------------------------ | ----------------- |
| Navigation bar not clear        | Simplified icons and added text labels           | ✅                 |
| Button colors too dull          | Increased contrast and used accent color         | ✅                 |
| Add Task button too small       | Enlarged and changed to a floating action button | ✅                 |
| No feedback when task completed | Added subtle animation and check icon            | ✅                 |
| No delete confirmation          | Added alert popup for confirmation               | ✅                 |

---

### 🧩 **Changes Made After Testing**

* Improved **color contrast** and **button visibility**
* Simplified **navigation icons with labels**
* Added **confirmation popup** for delete action
* Refined **typography and spacing** for better readability
* Completed **all remaining pages (Profile, Task Details, Settings, etc.)**

---

### 💬 **Summary Paragraph**

> After testing my *To-Do List App* prototype with 5 users,
> I discovered that users found the navigation unclear and buttons too small.
> Based on their feedback, I improved color contrast, added text labels to icons, and made interactive buttons larger.
> I also added animations for better feedback and completed all remaining pages.
> Users found the new design more intuitive and visually engaging.
